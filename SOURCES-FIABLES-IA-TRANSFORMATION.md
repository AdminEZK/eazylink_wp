# 📚 Sources Fiables pour Contenu IA Générative & Transformation Digitale

## 🎯 Guide de Référence EazyLink

Ce document liste les **sources autoritaires et vérifiables** à utiliser pour sourcer les articles EazyLink sur l'IA générative et la transformation digitale.

---

## 📊 1. Rapports Annuels / Trimestriels Majeurs

### McKinsey & Company

#### Technology Trends Outlook
- **Type** : Rapport annuel
- **Fréquence** : Annuel
- **URL** : https://www.mckinsey.com/capabilities/mckinsey-digital/our-insights/the-top-trends-in-tech
- **Pourquoi fiable** : Cabinet mondialement reconnu, analyses stratégiques basées sur large panel d'entreprises, données actualisées
- **Utilisation** : Tendances tech, prévisions marché, adoption IA

#### State of AI
- **Type** : Enquête mondiale annuelle sur l'IA
- **Fréquence** : Annuel + mises à jour trimestrielles
- **URL** : https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai
- **Pourquoi fiable** : Enquête auprès de grandes entreprises, analyse de l'adoption réelle et impacts économiques de l'IA générative
- **Utilisation** : Statistiques adoption IA, ROI, cas d'usage par secteur

**Format de citation** :
```
"X% des entreprises ont adopté l'IA générative selon le rapport State of AI 2025 de McKinsey"
```

---

### Gartner

#### Market Guides & Forecasts
- **Type** : Rapports annuels, prévisions trimestrielles
- **Fréquence** : Annuel / Trimestriel
- **URL** : https://www.gartner.com (abonnement requis)
- **Pourquoi fiable** : Référence mondiale pour l'analyse de maturité technologique
- **Utilisation** : Prévisions marché, maturité technologies, tendances

#### Hype Cycle for Emerging Technologies
- **Type** : Baromètre technologique annuel
- **Fréquence** : Annuel
- **Pourquoi fiable** : Méthodologie reconnue, analyse de maturité des technologies
- **Utilisation** : Positionnement technologies émergentes, prévisions adoption

**Format de citation** :
```
"Selon Gartner, l'IA générative atteindra le plateau de productivité d'ici 2027"
```

## 📋 Guide d'Utilisation pour Articles EazyLink

### Format de Citation Recommandé

**Pour statistiques** :
```
"48,3% des entreprises encouragent l'utilisation de l'IA selon l'étude State of AI 2025 de McKinsey & Company"
```

**Pour tendances** :
```
"Gartner prévoit que 75% des entreprises utiliseront l'IA générative d'ici 2027 (Hype Cycle 2025)"
```

**Pour données françaises** :
```
"Selon l'INSEE, 67% des entreprises françaises de plus de 10 salariés ont entamé leur transformation digitale en 2024"
```

### Section Sources et Références (Template)

```markdown
## Sources et Références

1. **State of AI 2025** - McKinsey & Company - 2025 - https://www.mckinsey.com/...
2. **Technology Trends Outlook** - McKinsey Digital - 2025 - https://www.mckinsey.com/...
3. **Hype Cycle for Emerging Technologies** - Gartner - 2025
4. **Digital Economy and Society Index (DESI)** - Commission Européenne - 2025 - https://digital-strategy.ec.europa.eu/...
5. **AI Index Report** - Stanford HAI - 2025 - https://aiindex.stanford.edu/
```

## ✅ Checklist Validation Sources

Avant de publier un article, vérifier :

- [ ] Minimum 3 sources différentes citées
- [ ] Sources datées (année de publication)
- [ ] Mix de sources (cabinets + institutions + médias)
- [ ] Liens URL fournis quand disponibles
- [ ] Organismes/auteurs clairement identifiés
- [ ] Pas de sources vagues ("selon des études", "les experts disent")
