## 🎯 CONFIGURATION GLOBALE YOAST

### Réglages Généraux

#### Titre du site
```
EazyLink | Experts & Solutions Intelligence Artificielle
```

#### Tagline
```
Votre partenaire IA pour transformer votre entreprise
```

#### Séparateur de titre
```
| (pipe)
```

### Réseaux Sociaux

#### Open Graph (Facebook)
- ✅ Activer les métadonnées Open Graph
- Image par défaut: Logo EazyLink (1200x630px)
- Type: Website

#### Twitter Card
- ✅ Activer les métadonnées Twitter
- Type de carte: Summary Large Image
- Username: @EazyLink (si disponible)

### Schema.org

#### Organisation
```json
{
  "@type": "Organization",
  "name": "EazyLink",
  "url": "https://eazylink.fr",
  "logo": "https://eazylink.fr/wp-content/uploads/logo-eazylink.png",
  "description": "Experts et solutions en intelligence artificielle pour entreprises",
  "sameAs": [
    "https://www.linkedin.com/company/eazylink",
    "https://twitter.com/eazylink"
  ]
}
```

### Fil d'Ariane (Breadcrumbs)
- ✅ Activer sur toutes les pages
- Séparateur: → (flèche)
- Préfixe: Accueil

### Sitemap XML
- ✅ Pages: Activé
- ✅ Articles: Activé
- ✅ Catégories: Activé
- ❌ Tags: Désactivé
- ❌ CGV: Désactivé
- ❌ Politique de confidentialité: Désactivé

## 🎨 IMAGES OPTIMISÉES SEO

### Dimensions recommandées :
- **Open Graph / Twitter**: 1200x630px
- **Logo**: 512x512px (format carré)
- **Images blog**: 1200x675px (16:9)
- **Images produits/services**: 800x600px

### Nommage des fichiers :
```
✅ Bon: experts-ia-intelligence-artificielle.jpg
❌ Mauvais: IMG_1234.jpg
```

### Alt Text :
```
✅ Bon: "Experts en intelligence artificielle accompagnant une entreprise"
❌ Mauvais: "image1"
```

1. **Immédiat** (Jour 1)
   - Configurer les SEO Titles et Meta Descriptions

2. **Court terme** (Semaine 1)

3. **Moyen terme** (Mois 1)
