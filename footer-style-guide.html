2. Classes CSS du Design System

Classes principales :
  • .footer - Container principal avec glassmorphism
  • .footer-container - Container interne avec marges
  • .footer-content - Grille 3 colonnes
  • .footer-column - Colonne individuelle
  • .footer-link - Liens de navigation (blanc avec effet hover orange)
  • .legal-link - Liens légaux (gris avec hover orange)
  • .social-icon - Icônes sociales avec glassmorphism
  • .copyright-section - Section copyright en bas
/* Footer principal */
.footer {
    background: transparent;
    backdrop-filter: blur(20px);
    border: 1px solid rgba(255, 255, 255, 0.2);
    border-radius: 15px;
    max-width: 1518px;
    margin: 50px auto;
}

/* Grille 3 colonnes */
.footer-content {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 3rem;
}

/* Liens avec effet hover */
.footer-link {
    color: rgba(255, 255, 255, 0.9);
    padding: 0.5rem 1rem;
    border-radius: 25px;
}

.footer-link:hover {
    background: rgba(255, 255, 255, 0.1);
    transform: translateY(-1px);
}

4. Comportement Responsive

Mobile (0-767px) :
  • 1 colonne verticale
  • Texte centré
  • Width: calc(100% - 40px)
  • Margin: 40px auto
Desktop (≥768px) :
  • 3 colonnes en grille
  • Texte aligné à gauche
  • Width: calc(100% - 60px)
  • Margin: 50px auto
  • Gap: 2.5rem entre colonnes
