## 🎯 Matrice de Décision Automatique

### Règles d'Attribution de Catégorie

L'agent IA utilise cette matrice pour déterminer automatiquement la catégorie :

### Algorithme de Scoring

```javascript
function determineCategory(sujet, keywords) {
  const scores = {};
  
  for (const [category, rules] of Object.entries(categoryRules)) {
    let score = 0;
    
    // Score basé sur les mots-clés
    for (const keyword of keywords) {
      if (rules.keywords.some(k => keyword.toLowerCase().includes(k))) {
        score += 10;
      }
    }
    
    // Score basé sur le sujet
    for (const ruleKeyword of rules.keywords) {
      if (sujet.toLowerCase().includes(ruleKeyword)) {
        score += 5;
      }
    }
    
    scores[category] = score;
  }
  
  // Retourner la catégorie avec le score le plus élevé
  return Object.keys(scores).reduce((a, b) => scores[a] > scores[b] ? a : b);
}
```

## 🚀 Utilisation dans l'Agent IA

L'agent utilise ce PRD pour :

1. **Analyser le sujet** reçu via Telegram
2. **Rechercher les mots-clés** avec Perplexity
3. **Scorer chaque catégorie** selon les règles
4. **Sélectionner la catégorie** avec le score le plus élevé
5. **Générer l'article** optimisé pour cette catégorie
6. **Publier sur WordPress** avec le bon category_id
